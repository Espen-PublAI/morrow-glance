# Clock

Shows the current time in a chosen timezone, with an optional label.

| Setting    | Type     | Notes                                                                         |
| ---------- | -------- | ----------------------------------------------------------------------------- |
| `label`    | text     | Shown above the time in small caps.                                           |
| `timeZone` | timezone | IANA name such as `Europe/Oslo`. Defaults to the display timezone when added. |

Views: `digital`. Default size 4 × 2, minimum 2 × 1.
