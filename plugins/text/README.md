# Text

A user-authored note, welcome message, or announcement.

| Setting | Type     | Notes                                                     |
| ------- | -------- | --------------------------------------------------------- |
| `label` | text     | Shown above the text in small caps.                       |
| `text`  | textarea | The message. Long text wraps; keep it short for a glance. |

Views: `note`. Default size 8 × 2, minimum 3 × 1.
