# Geographic data

Generated by `npm run geo` (`scripts/build-geo.mjs`). Do not edit by hand.

| File          | Contents                                                                                           | Source and licence                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `cities.json` | City index for the Admin picker: name, country, timezone, alternate names, population, coordinates | [GeoNames](https://www.geonames.org/) `cities15000`, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `zones.json`  | One representative coordinate per IANA zone, its largest city                                      | Derived from the same GeoNames data                                                                            |
| `land.json`   | 96 × 48 dot-grid land mask for the map view                                                        | [Natural Earth](https://www.naturalearthdata.com/) 1:110m land via `world-atlas`, public domain                |

The city index is loaded lazily by Admin only. Players ship the two small files.
